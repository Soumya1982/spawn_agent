Spawn Agent + IBM Bob Repair Agent

Self-healing system for order_workflow.py — log watching, root cause analysis, automated fix & rerun

Components Built

FileRoleRuns as
agents/spawn_agent.py Watches log_analysis/ for new run logs; triggers repair when ERROR or WARNING events are found Long-running daemon or one-shot CLI
agents/bob_repair_agent.py IBM Bob Repair Agent — performs RCA, applies fixes, reruns workflow, verifies result Spawned by SpawnAgent or standalone CLI
agents/agent_fixes.py Fix library — one class per known error/warning event type; fully pluggable Imported by BobRepairAgent
agents/README.md Full operational guide with extension patterns Documentation

Architecture

order_workflow.pyRuns transformation pipeline, writes log_analysis/workflow_log_*.json
↓ detected by
SpawnAgentPolls log dir every N seconds. When a new log contains ERROR/WARNING, extracts issues and spawns BobRepairAgent
↓ spawns
BobRepairAgent 1. analyse() → classify each issue by severity, build RCA report, identify matching fixes
2. fix(rca) → apply AgentFix actions (patch CSV, restore files, etc.)
3. rerun() → subprocess: python order_workflow.py …
4. verify() → parse new log, check if clean — repeat up to N times

Severity & Fix Mapping

Event codeSeverityAuto-fix applied
file_not_foundCRITICALSearch for backup CSV and restore it
load_failed / export_failedCRITICALLog escalation — manual fix required
missing_quantityHIGHPatch CSV cell: Quantity = 1
datatype_mismatchHIGHLog recommendation for manual correction

duplicate_hardMEDIUMWorkflow auto-drops; agent acknowledges
duplicate_businessLOWAcknowledged — human review required
missing_columnLOWAcknowledged — schema review required

Step-by-Step Operational Guide

1
Install dependencies 
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
No extra packages required — the agents use only stdlib + pandas.
2
Run SpawnAgent in watch mode (recommended for live pipelines) 
python agents/spawn_agent.py
Polls log_analysis/ every 10 s. Detects new logs and spawns BobRepairAgent automatically. Optional flags: 
python agents/spawn_agent.py \
    --log-dir log_analysis \
    --poll-interval 10 \
    --max-repair-attempts 3
3
Run SpawnAgent once (CI / scheduled task) 
python agents/spawn_agent.py --once
Processes every unprocessed log file in one pass, then exits with code 0.
4
Target a specific log file with BobRepairAgent directly 
python agents/bob_repair_agent.py \
    --log log_analysis/workflow_log_20260828T061035Z_18f06bcd.json
Exit codes: 0=repaired   2=not auto-fixable   3=attempts exhausted
5
Add a custom fix for a new error type

Open agents/agent_fixes.py, add a class that extends AgentFix, implement matches() and apply(), then append an instance to FIX_REGISTRY. No other files need to change.

6
Escalation path (when repair is not possible)

If all attempts are exhausted, SpawnAgent logs ❌ Escalate to manual review. At that point: inspect the log JSON, manually correct order_history.csv, then rerun python order_workflow.py --input order_history.csv.
